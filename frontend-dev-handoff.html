CareerVerse AI

React/Vite frontend for a student and admin career-readiness platform. The UI supports student registration, role-based login, profile management, resume ATS scoring, skill-gap analysis, and admin student monitoring.

Stack React 19, Vite 8, plain CSS, browser Fetch API.
API base VITE_API_BASE_URL, falling back to http://localhost:8080.
Session storage JWT session persisted in localStorage as careerverse-session.
Primary routes Single-page app with conditional student/admin dashboard rendering.

Application Structure

File Responsibility
src/App.jsx Owns session state, login/logout, landing page, and dashboard selection by role.
src/services/api.js Central fetch helper for JSON and multipart requests with optional bearer token headers.
src/components/RegisterPanel.jsx Student registration form posting to /api/auth/register/student.
src/components/LoginPanel.jsx Student/admin login form posting to /api/auth/login and validating role.
src/components/StudentDashboard.jsx Loads and updates student profile through /api/student/profile.
src/components/AdminDashboard.jsx Loads registered students from /api/admin/students.
src/components/AtsAnalyzer.jsx Uploads resume files to /api/ai/ats-score and displays ATS results.
src/components/SkillGapAnalyzer.jsx Uploads resume plus job description to /api/ai/skill-gap.

User Flows

  1. Visitor lands on the auth screen, creates a student account, or signs in with the student/admin login panels.
  2. On successful login, the backend returns a session object with role, name, and token. The frontend stores it in localStorage.
  3. Student users see profile editing, ATS analysis, and JD skill-gap analysis.
  4. Admin users see the registered student table plus the same analysis modules.
  5. Logout clears the stored session and returns the user to the landing/auth screen.

Backend Contract

Endpoint Method Payload Expected response
/api/auth/register/student POST JSON student fields Registration message and email.
/api/auth/login POST JSON email and password Session with role, full name, and JWT token.
/api/student/profile GET/PUT Bearer token; PUT sends JSON profile Student profile object.
/api/admin/students GET Bearer admin token Array of student records.
/api/ai/ats-score POST Multipart resume Score, summary, strengths, improvements, and keywords.
/api/ai/skill-gap POST Multipart resume and jobDescription Match score, summary, matched skills, missing skills, and action plan.

Runbook

  • Install frontend dependencies with npm install inside frontend.
  • Run the development server with npm run dev.
  • Set VITE_API_BASE_URL when the backend is not running on localhost:8080.
  • Build production assets with npm run build.
  • Lint with npm run lint.

Known Notes

  • The UI is currently a single-page app without a router.
  • Demo credentials are prefilled in the login panels for student and admin testing.
  • File inputs accept PDF, DOC, DOCX, PPT, PPTX, and TXT files.
  • Errors from failed API requests are shown directly from the backend response text.
  • The styling is maintained in src/App.css with responsive breakpoints at 900px and 700px.
